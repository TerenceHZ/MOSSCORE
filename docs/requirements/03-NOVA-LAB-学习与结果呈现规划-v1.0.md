## 一、先给结论

NOVA LAB 不是一个普通的行情页，它的核心价值是：

> **把“市场状态 → 候选币 → 单币证据 → 风险/观察 → 历史验证”串成一条可解释的决策链。**

我们要接的不是它的外观，而是它的**结果结构和判断顺序**。

550C 当前视觉负责“看”，NOVA LAB 的结果负责“判断”。  
最终监控软件应该做到：

- 第一眼看到：现在市场能不能做
- 第二眼看到：现在最值得看的币是哪几个
- 第三眼看到：为什么是它，证据是什么
- 出现变化时：软件主动提醒，而不是用户自己翻

## 二、NOVA LAB 的结果分层

### L1 市场结论层

**大盘势头 / Market Regime**

这是整个页面最上层的结论，用来回答：

> 现在适合不适合做多/做空/只观察？

核心字段：

| 字段 | 含义 | 呈现方式 |
|---|---|---|
| `regime` / `regime_code` | 强势 / 稳定 / 弱势 / 差 | 大字状态 + 颜色 |
| `score` | 0–100 总分 | 大数字 |
| `confidence` | 置信度 | 小标签 |
| `data_completeness_pct` | 数据完整度 | 进度/百分比 |
| `btc_change_24h_pct` | BTC 24h | 涨跌色 |
| `liquid_symbol_count` | 有效流动合约数 | 数量 |
| `factors[]` | 市场广度、BTC锚点、流动性、信号强度 | 四项分解 |
| `recommendation` | 研究建议 | 一句话 |
| `execution_note` | 执行说明 | 灰字 |
| `btc_liquidity_guard` | BTC 流动性守卫 | 正常/预警/异常 |

四档含义：

| 档位 | 分数 | 已有仓位风控 |
|---|---|---|
| 强势 | 75–100 | 给利润更多空间 |
| 稳定 | 55–74.9 | 正常分批止盈 |
| 弱势 | 35–54.9 | 10% 内优先锁盈 |
| 差 | 0–34.9 | 优先保本、锁盈、退出 |

注意：这四档只影响**已有仓位的风控**，不改变开仓条件。

### L3 单币证据层

点开某个候选币后，NOVA 展示“为什么是它”：

1. **策略为什么选中**
   - `strategy_reasons[]`

2. **评分明细**
   - 基础分、1m、3m、5m、15m、24h 位置、成交额、回撤、微观盘口

3. **盘面参考**
   - 扫描参考价
   - 5 分钟 / 15 分钟
   - 距短线高点回撤
   - 1 分钟成交额
   - 检测时间

4. **全网持仓核验**
   - 全网 OI
   - 15 分钟 OI
   - 1 小时 OI
   - 持仓主导所
   - 主导所占比
   - 跨所价差

5. **交易所明细**
   - 交易所 / OI / 24h 成交 / 资金费率 / 价格

6. **全网 OI 历史**
   - 起点 OI、当前 OI、区间增减、区间变化、覆盖时长、数据点

7. **公开交易员开仓成本**
   - 多空开仓价、未平仓仓位

8. **代币历史价格与状态**
   - 每次推荐的时间、阶段、价格

9. **监控结果分析与判断**
   - 当前阶段
   - 策略分
   - 5 分钟 / 24 小时
   - 持仓变化判断
   - OI 数据质量说明
   - 公开交易员成本说明

### L4 观察与风险层

**MM 重点观察池**

NOVA 对已知 MM 项目、反复横跳项目做独立跟踪：

- 三阶段适配度
- 历史入场价
- 价格 / 成交 / OI / 资金费率
- 成本代理
- 持仓快增 / 快退

OI 快增规则：

```text
全网 OI 5 分钟 +5%
或 15 分钟 +10%
并且名义持仓净增至少 100,000 USDT
交易所覆盖口径必须稳定
```

OI 快退同理，方向相反。

**重要限制：**

- OI 增加可能来自新增多仓、空仓或对冲仓，不能单独判断方向
- 公开交易员成本只能辅助观察，不能证明未来方向
- MM 状态和成本是市场数据代理，不代表识别了真实账户

### L5 补充观察层

**低市值项目 / 低市值十币**

字段：

- 排名
- 币种 / 名称
- 币安现价
- 流通市值
- 24h 涨跌
- 主策略阶段
- 研究动作

规则：

- 市值排名不代表买入信号
- 只有与主策略阶段同时满足才进入研究
- 初筛观察：只记录价格，不追涨
- 重点候选：核对成交量、OI、距初筛价差
- 开仓信号：追涨距离可控时才补足研究仓

**上一周涨幅榜与允许开仓信号**

逐币展示：

- 首次上榜
- 首次推荐
- 首次允许开仓
- 开仓后最高涨幅

### L6 历史验证层

**历史回测 / 纸面交易**

页面有，但公开页面隐藏了纸面账户数据：

- `public-no-paper` 隐藏纸面总览、逐笔交易
- 公开页只展示研究结果，不展示真实账户

可展示的研究结果：

- 净利润
- 收益率
- 胜率
- 交易数
- 手续费
- 最大回撤
- 10x / 20x 分账
- 止盈/止损/时间退出原因
- 容量拒绝数

这一层建议**不要放进主监控首屏**，放到“历史/研究”二级页。

## 五、数据接入方式

NOVA LAB 页面实际使用：

```text
/api/live
/api/candidates
/api/asset?asset=SYMBOL
/api/paper-accounts
/api/history-backtest/status
/api/history-backtest/run
```

页面刷新：

```text
网页 5 秒刷新
主策略 30 秒
全网核验 60 秒
```

建议我们的软件：

| 数据 | 频率 |
|---|---|
| 大盘状态 | 10–30 秒 |
| 候选队列 | 5–10 秒 |
| 选中币详情 | 打开时 + 15 秒 |
| 全网 OI | 60 秒 |
| 事件流 | 5 秒 |

必须先解决一个问题：

> **NOVA LAB 是你自己的服务，还是别人的页面？**

- 如果是你自己的服务：直接接 API，最稳
- 如果是别人的页面：不能长期依赖对方接口和数据结构，需要确认授权，或者用同样的数据源自己计算
- 无论哪种，都不建议把对方页面嵌进软件里
