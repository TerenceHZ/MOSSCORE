文档状态：需求沟通稿，未进入开发

项目：MOSS CORE · 550C 神经星环监控桌面端

---

## 1. 产品目标

做一个只在一个主窗口内运行的加密合约监控软件：

```text
导入监控
+ 自选重点
+ 全网多签数据
+ MOSS 工作轨迹
```

核心原则：

- 不做全市场大表
- 先由用户导入需要监控的代币
- 再从导入中挑出自选重点
- 多签只做数据查询和累计证明
- 所有结果可解释、可追溯
- 不自动下单

---

## 2. 三个核心模块

### 模块 1：导入监控

定位：

```text
用户手动导入需要监控的代币
系统只监控这些代币
不再扫描全市场
```

层级：

```text
辅助层级
```

规则：

- 支持单个添加
- 支持批量粘贴
- 支持 CSV
- 自动补 `USDT`
- 校验币安合约是否存在
- 重复自动去重
- 无效币明确提示
- 导入前预览：新增 / 重复 / 无效

建议上限：

```text
100 个
```

### 模块 2：自选重点

定位：

```text
从导入监控中挑出的重点代币
重点监控、优先播报、优先展示
```

层级：

```text
主层级
```

规则：

- 自选是导入的子集
- 加入自选 → 自动进入导入
- 从导入删除 → 自选一起删除
- 从自选降级 → 保留在导入
- 一个币只有一个状态，不重复
- 自选默认排在导入前面
- 自选卡片和模块视觉更重

建议上限：

```text
20 个
```

### 模块 3：多签数据

定位：

```text
链上多签额度查询与累计证明
不是资金流监控
```

规则：

- 只记录多签额度
- 累计全部历史
- 只加不减
- 不追踪流入流出
- 不扣减
- 不算当前余额
- 不判断资金方向
- 不直接下结论“市值团队介入”

## 3. 布局总览

只使用一个主窗口。

```text
┌────────────────────────────┬──────────────────────────┬────────────────────────────┐
│ ★ FOCUS 自选模块            │                          │ 信号事件 / 多签证明         │
│                            │                          │                            │
├────────────────────────────┤       NEURAL 星环         ├────────────────────────────┤
│ ○ IMPORTED 导入模块         │                          │ MOSS 工作轨迹               │
│                            │                          │                            │
├────────────────────────────┼──────────────────────────┼────────────────────────────┤
│ ○ 导入当前卡                │      星环下缘保持可见      │ ★ 自选当前卡                │
├────────────────────────────┴──────────────────────────┴────────────────────────────┤
```

关键约束：

- 星环不为了底部压缩
- 底部六格不动

- 中间留空给星环
- 左栏底部为导入卡让出约 90px
- 右栏使用现有间隙放自选卡
- 不打开第二个软件窗口

## 4. 左侧模块

左侧不再是一个平铺矩阵，而是两个大模块：

```text
★ FOCUS 自选模块
○ IMPORTED 导入模块
```

排序：

```text
ENTRY > WATCH > LOW > MM/OI
再按分数
再按触发时间
```

每个模块显示：

- 模块名称
- 今日/近期触发次数
- 币种列表
- 每个币：币种、阶段、分数、触发时间、多签额度标记

建议高度：

```text
自选 55%
导入 45%
```

视觉：

- 自选：亮金、实线、较强背景
- 导入：暗金、细线、纯黑背景
- 两个模块各自滚动

点击行为：

- 点击模块 → 打开“历史监控”抽屉
- 点击模块内的币 → 打开“当前详情”抽屉

## 5. 底部双卡 + 六格

### 底部左侧：导入当前卡

小型选择卡，高度约 78–90px：

```text
○ IMPORTED · 导入
WIF   WATCH   81.2
15:42:31 抓取
```

### 底部右侧：自选当前卡

同样大小，但视觉更重：

```text
★ FOCUS · 自选
BLESS   ENTRY   97.0
15:42:31 抓取
```

规则：

- 每次抓取只产生一个代币
- 抓到自选币 → 更新右卡
- 抓到导入币 → 更新左卡
- 另一张卡保持上一次抓取
- 同一币重复抓取 → 更新时间，不重复新增
- 点击整卡 → 打开右侧详情抽屉
- 不放“详情”小按钮
- 六格默认跟随自选卡
- 点击导入卡 → 六格切到导入币
- 点击自选卡 → 六格切回自选币

### 六格参数

六格保持不变，不拆成两套。

建议字段：

```text
24H / 5M / 1M QV / 全网OI / 回撤 / 策略分
```

待最终确认字段。

## 6. 星环与红眼

星环保持原尺寸，不因底部信息压缩。

### 红眼状态链

```text
待机 → 锁定 → 抽取 → 飞行 → 到达 → 窗口更新 → 回到待机
```

### 待机

- 轻微呼吸
- 瞳孔缓慢收缩/放大
- 淡红光晕
- 不持续闪

### 锁定

- 瞳孔收紧
- 红色波纹
- 星环节点亮
- 红眼偏向目标

### 抽取

- 红眼中心亮
- 拉出光粒
- 自选暗金，导入白色

### 飞行

自选：

```text
慢、粒子大、拖尾长、轻微悬停
```

导入：

```text
快、粒子小、拖尾短、不悬停
```

### 到达

- 卡片反差闪一次
- 数字解码滚动
- 自选暗金呼吸
- 导入白色快闪
- 播放对应音效

## 7. 60 秒更新提示

窗口更新后：

```text
0ms      粒子到达
0–300ms  反差闪一次
300ms    数字落定
300ms–60s 持续高亮
60s      0.6–0.8 秒淡出
```

规则：

- 不是闪 60 秒，是持续高亮
- 自选暗金，导入白色，多签金白
- 底部一条 60 秒进度线
- 新数据到达重新计时
- 只高亮更新的窗口
- 不闪全屏
- 窗口不可见也继续计时

## 8. 三个抓取点与音效

### 自选抓取

```text
红眼 → 暗金粒子 → 慢速弧线 → 右下自选卡
```

音效：

```text
低沉、温暖、有重量
约 0.35–0.5 秒
```

### 导入抓取

```text
红眼 → 白色小点 → 快速 → 左下导入卡
```

音效：

```text
轻、快、短
约 0.1–0.2 秒
音量低
```

### 多签发生

```text
多签窗口 → 光晕扩散 → 数字滚动 → 累计额度更新
```

音效：

```text
金属、清脆、有回响
约 0.3–0.5 秒
```

音效规则：

- 三类可单独关闭
- 可调总音量
- 可设静音时段
- 同一事件不重复
- 多事件合并，不叠噪音
- 窗口不在前台时是否播放可配置

## 9. 多签模块

### 口径

```text
每次多签 = 一条新增记录
累计额度 = 从第一条记录开始，所有新增金额相加
播报 = 本次新增 + 累计额度
```

例子：

```text
11-02  +200,000
11-04  +1,000,000

本次播报：
本次新增 +1,000,000
累计额度 1,200,000
记录 2 笔
```

### 播报条件

```text
本次新增 ≥ 200,000 USD
或
累计额度首次达到/超过 200,000 USD
```

### 记录内容

```text
时间
币种
链
多签地址
本次新增
累计额度
签名门槛
代币数量
当时 USD
占流通比例（如可得）
数据来源
验证时间
证据链接
```

### 历史抽屉

点击播报、左侧 MS 标记、多签卡：

```text
MULTISIG HISTORY
累计额度
记录笔数
首次记录
最近记录
覆盖链
历史列表
```

支持：

- 今天 / 近 3 天 / 近 7 天 / 全部
- 按链筛选
- 按金额筛选
- 导出

### 显示位置

- 左侧币种行：`MS 1.2M`
- 左下/多签窗口：累计额度
- 右侧多签列表
- 顶部播报条

## 10. 抽屉

只使用主窗口内抽屉，不新开软件窗口。

打开方式：

- 点击左侧模块 → 历史监控
- 点击模块内币 → 当前详情
- 点击底部当前卡 → 当前详情
- 点击多签入口 → 多签历史

抽屉标签：

```text
[当前详情] [历史监控] [多签历史]
```

### 当前详情

- 币种、阶段、分数
- 一句话结论
- 关键价格/动量/成交额
- 多签累计额度
- 10x / 20x 风控
- 数据时间

### 历史监控

- 今天 / 近 3 天 / 近 7 天 / 全部
- 触发次数
- 按天分组
- 时间、币种、触发类型、阶段、分数、原因
- 点击某条 → 当前详情

### 多签历史

- 累计额度
- 记录笔数
- 每条记录
- 证据链接

---

## 11. 历史监控触发类型

只记录“触发监控关注”的事件：

- 进入初筛观察
- 升级重点候选
- 升级开仓信号
- 降级
- OI 快增 / 快退
- 多签累计达到阈值
- 低市值进入初筛
- 重新进入监控

不记录每一次普通扫描。

---

## 12. MOSS 工作轨迹

保留异动日志，定义为 MOSS 工作轨迹。

记录：

- 扫描开始/完成
- 数据源更新/延迟/失败
- 评分变化
- 阶段升级/降级
- 多签验证
- 提醒发射
- 窗口更新
- 错误/重试

视觉：

```text
[时间] [模块] 内容
```

- 成功：金
- 警告：暗金
- 错误：红
- 不闪烁、不弹窗、不发声
- 默认滚到最新
- 用户上滚暂停
- 可暂停、清屏、导出

位置：

- 右侧下半栏常驻
- 不隐藏到设置页

## 13. 主次视觉规则

| 维度 | ★ 自选 | ○ 导入 |
|---|---|---|
| 颜色 | 暗金 `#9A7A3A` + 暖金高光 | 灰白 `#F2F0E8` 45–60% |
| 边框 | 实线 + 四角重线 | 细线 |
| 字号 | 更大 | 小一档 |
| 背景 | 黑金渐变 | 纯黑 |
| 光效 | 有外发光 | 无外发光 |
| 粒子 | 大、慢、长拖尾 | 小、快、短拖尾 |
| 到达 | 金色呼吸 | 白色快闪 |
| 声音 | 有 | 默认无 |
| 默认激活 | 是 | 否 |

- 声音

- 显示模块

## 16. 数据与后端

当前桌面版是 WebView2 本地界面，只有视觉和模拟数据，没有真实监控服务。

真实实现需要：

- 行情服务
- 信号计算服务
- 多签数据服务
- 历史存储
- 桌面端与后台通信

建议架构：

```text
交易所 API / WebSocket
链上数据源
        ↓
后台服务
  - 扫描
  - 评分
  - 阶段
  - OI / 多签
  - 历史
        ↓
API / SSE / WebSocket
        ↓
MOSS CORE WebView2 桌面端
```
