# 第二参考站对比与底部六格字段建议 v1.0

文档状态：分析稿  
整理时间：2026-11-02  
参考站一：NOVA LAB `https://novalive.cn/lab/`  
参考站二：币安合约监控 `http://43.106.19.243:8765/market-signals`  
用途：确定 MOSS CORE 主窗口底部六格的最终信息，不再继续加第七格。

## 1. 结论

底部六格建议固定为：

```text
24H 涨跌
5M 动量
1M QV / 持续资金
全网 OI / 5M·15M 变化
回撤
策略分 / 阶段
```

推荐标签：

```text
24H    5M    1M QV    全网 OI    回撤    策略分
```

这不是简单照搬任何一个站，而是把两站的信息压进六个位置：

- NOVA 负责：分数、阶段、阈值、24H、QV、动量、回撤
- 第二站负责：多周期动量、持续资金、成交/盘口、OI 多周期、风险与下一步
- MOSS 只保留：能直接回答“现在能不能看、为什么看、风险在哪”的六个量

## 3. 第二站真正新增的信息

### 3.1 多周期动量

第二站同时看：

```text
1m / 5m / 15m / 30m / 60m
```

这比 NOVA 的 1m / 3m / 5m 更适合判断“刚启动”还是“已经走了很久”。

但六格不能放五个周期，否则会变成小表格。  
建议六格只显示 **5M 主值**，副值显示 `1m / 3m`，弹窗里再显示完整五段。

### 3.2 持续资金

第二站把“持续资金”作为独立列，并拆分：

```text
资金 30 秒 / 60 秒
偏多 / 偏空
现货参照
```

这是第二站最有价值的新增信息之一。  
但六格已经没有第七格，建议把它压进 **1M QV 的副值**：

```text
主值：1M QV 70.5K
副值：资金 +3.2M · 30s 偏多
```

这样既保留 NOVA 的 QV 阈值，也保留第二站的“资金是不是持续”的判断。

### 3.3 OI 多周期与质量

第二站不是只给一个 OI 数字，而是给：

```text
5m / 15m / 30m / 1h 变化
增仓阶段
OI 增量质量
价格-OI 同步/背离
数据是否新鲜
```

六格建议：

```text
主值：全网 OI
副值：5M +6.2% · 15M +11.8%
```

如果 OI 数据缺失或过期，必须明确写“待核验/已过期”，不能显示一个看似正常的旧值。

### 3.4 风险 / 下一步

第二站把结论拆成：

```text
状态
决策盒
复核阶段
路径风险
阻断原因
```

这比单纯给一个分数更可解释。  
MOSS 的六格用 **回撤 + 策略分/阶段** 承接，完整“下一步”放在弹窗，不塞进六格。

### 3.5 资金确认、重点观察、自选

第二站有独立入口：

```text
全部 / 我的自选 / 重点观察 / 持仓快增 / 资金确认 / HYPE / Alpha / 韩所买盘
```

这验证了 MOSS 的模块划分：

```text
导入监控
自选重点
多签证明
```

但 MOSS 不照搬它的多标签页，仍保持一个主窗口 + 左侧两个模块。

## 4. 底部六格最终建议

| 位置 | 推荐标签 | 主值 | 副值 | 回答的问题 |
|---|---|---|---|---|
| 1 | 24H | 24 小时涨跌幅 | 北京日涨跌 / 距 24H 高点 | 这个位置是不是已经太高？ |
| 2 | 5M | 5 分钟动量 | 1m / 3m 动量 | 是不是刚刚启动？ |
| 3 | 1M QV | 1 分钟成交额 | 持续资金 30s/60s · 成交/均量 | 有没有真实成交和持续资金？ |
| 4 | 全网 OI | 当前全网持仓 | 5M / 15M 变化 · 数据新鲜度 | 持仓是在配合还是背离？ |
| 5 | 回撤 | 距 24H 高点回撤 | 触发后最大回撤 | 追进去的风险有多大？ |
| 6 | 策略分 | 0–100 分 | ENTRY / WATCH / LOW / 观察 | 现在处于哪个阶段？ |

### 4.1 为什么是这六个

- **24H**：判断位置，防止把已经走完的币当成刚启动。
- **5M**：判断触发速度，是主信号，不是辅助。
- **1M QV + 持续资金**：判断流动性和资金是否持续；只有成交没有持续资金，容易是脉冲。
- **全网 OI**：判断持仓是否配合；价格涨、OI 不涨，信号质量下降。
- **回撤**：判断追高风险；没有回撤数据的信号不能直接给高置信度。
- **策略分 / 阶段**：把前面五个量收束成一个可执行的结论。

### 4.2 为什么不再加第七格

- 资金费率：重要，但属于持有成本，不是入场第一判断；放详情。
- 盘口深度：重要，但变化快，六格固定显示容易过期；放详情。
- 聪明钱 / 参与者：第二站有，但数据源和口径还不稳定；先放详情，验证后再考虑。
- 多签：MOSS 的独立模块，不能挤进行情六格。
- 完整 1/5/15/30/60：信息密度过高，六格会变成表格；5M 主值 + 弹窗完整周期更合理。

## 5. 六格的显示规则

### 5.1 主次颜色

- 自选：暗金主值，暖金副值
- 导入：灰白主值，低亮副值
- 数据缺失：灰色 `待核验`
- 数据过期：暗红或灰色 `已过期`，不能沿用旧值装作实时

### 5.2 新鲜度

每个值都应该能追溯到更新时间：

```text
数据时间：15:42:31
数据源：公开行情 / 公开多签
缺失项：OI 待核验
```

六格底部或弹窗里显示，不在每一格重复堆时间。

### 5.3 联动

- 默认跟随自选卡
- 点导入卡，六格切到导入币
- 点自选卡，六格切回自选币
- 新流星到达只更新对应卡片/窗口
- 15 分钟内保持新鲜态，超过 15 分钟恢复普通态
