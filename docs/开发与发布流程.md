# MOSS CORE 开发与发布流程

> 适用两台电脑：家里（开发）+ 现在这台（验收/发布）
> 唯一源文件：`desktop-webview/index.html`

---

## 一、路径约定

| 位置 | 用途 | 是否手改 |
|---|---|---|
| `desktop-webview/index.html` | **唯一源文件**，界面/前端逻辑 | ✅ 改这里 |
| `desktop-webview/*.cs` | Windows 内核（权限、激活、下单桥接） | ✅ 改这里 |
| `mac-electron/main.js` | macOS 内核 | ✅ 改这里 |
| `cloud/*.py` | 云端服务 | ✅ 改这里 |
| `website/index.html` | 官网 | ✅ 改这里 |
| `vendor/agent-neural/index.html` | 副本，**不要手改** | ❌ 由同步脚本覆盖 |
| `mac-electron/index.html` | 副本，**不要手改** | ❌ 由同步脚本覆盖 |

**核心原则：前端只改 `desktop-webview/index.html`，改完自动复制到另外两处。**

---

## 二、家里电脑（开发）流程

### 1. 改代码

```
前端/界面   → desktop-webview/index.html
Windows 内核 → desktop-webview/*.cs
Mac 内核    → mac-electron/main.js
云端        → cloud/*.py
官网        → website/index.html
```

### 2. 本地自测

```powershell
# 启动 Windows 客户端看效果
C:\Users\<你的用户名>\Desktop\MOSS CORE.lnk
```

或者直接编译跑：

```powershell
dotnet publish desktop-webview\MossCore.csproj -c Release -r win-x64 --self-contained true -o release\publish
```

### 3. 改版本号（如果发版）

需要改这几处：

```
mac-electron/package.json         "version": "1.0.xx"
desktop-webview/MossCore.csproj    <Version>1.0.xx</Version>
website/index.html                 版本号文字 + zip 文件名
```

### 4. 提交并推送

```powershell
cd D:\数据库

# 只提交源码，不要提交打包产物
git add desktop-webview/ mac-electron/ cloud/ website/ scripts/ docs/
git status                       # 确认列表里没有 zip / exe / dist

git commit -m "feat(范围): 说明 (v1.0.xx)"
git push origin main
```

**如果 push 卡住，加代理：**

```powershell
git -c http.proxy=socks5h://127.0.0.1:7890 -c https.proxy=socks5h://127.0.0.1:7890 push origin main
```

### 5. 通知这边

在家里推完之后，告诉这边的助手：「同步最新代码」。

## 三、现在这台（验收/发布）流程

### 一键同步

双击：

```
D:\数据库\scripts\同步更新.bat
```

或命令行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\数据库\scripts\sync-all.ps1
```

### 脚本自动完成的 7 步

```
1. 拉取 GitHub 最新代码
   · 有本地未提交改动 → 先 git stash 备份

2. 同步 index.html
   · desktop-webview → vendor/agent-neural + mac-electron + 安装目录

3. 检查 C# 是否比 exe 新
   · 新的才编译（省时间）

4. 部署 exe 到 C:\Users\ROG\MOSS CORE\
   · 哈希不同才复制

5. 检查云端 .py
   · 对比服务器 md5，不同才上传并重启服务

6. 启动客户端

7. 验证 /queue 接口
```

### 查看结果

每次运行会生成日志：

```
D:\数据库\backup\sync-logs\sync-YYYYMMDD-HHMMSS.json
```

### 打包（只在明确要求时做）

```powershell
# 1. 准备素材
$stage = 'C:\MOSS-MIN'
Get-ChildItem $stage | Remove-Item -Recurse -Force
Copy-Item 'C:\Users\ROG\MOSS CORE\MOSS CORE.exe' $stage
Copy-Item 'C:\Users\ROG\MOSS CORE\index.html' $stage
# ... 其他资源文件

# 2. 压缩
$ver = 'v1.0.xx-YYYYMMDD.1'
Compress-Archive -Path "$stage\*" -DestinationPath "D:\数据库\release\MOSS-CORE-Desktop-$ver.zip"

# 3. 复制到桌面
Copy-Item "D:\数据库\release\MOSS-CORE-Desktop-$ver.zip" "$env:USERPROFILE\Desktop\MOSS CORE 桌面版-$ver.zip"

# 4. 上传官网
scp -i C:\Users\ROG\Downloads\moss_core.pem "...zip" ubuntu@43.160.232.254:/var/www/moss-site/downloads/
```

## 四、常见问题排查

### Q1: 改了界面但客户端没变化

```
原因：改了代码但没同步到安装目录
解决：跑一次 同步更新.bat
```

### Q2: 改了 C# 但功能没生效

```
原因：exe 还是旧的
解决：同步脚本会自动检测 C# 时间戳，重新编译
```

### Q3: 改了云端但接口没变化

```
原因：服务器上还是旧 .py
解决：同步脚本会对比 md5 自动上传
```

### Q4: 两台设备数据不同步

```
检查项：
1. 两边 index.html 哈希是否一致
2. 云驱动是否 active（控制台看 [CLOUD] driver started）
3. /queue 接口是否正常
```

### Q5: push 很慢或失败

```
用代理：
git -c http.proxy=socks5h://127.0.0.1:7890 -c https.proxy=socks5h://127.0.0.1:7890 push
```
