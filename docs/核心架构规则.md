# MOSS CORE 核心架构规则

> **本文档是项目的强制约束。任何修改都不得违反。**
> 违反前必须先与项目负责人确认。

---

## 一、最高原则：云端是唯一数据源

```
┌─────────────────────────────────────────────────────────┐
│                     云 端（唯一真相）                     │
│  · 采集行情    · 计算队列    · 记录历史    · 记录异动     │
└─────────────────────────────────────────────────────────┘
                            │
                 所有设备只读，不写，不算
                            │
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   ▼
   Windows 客户端       Mac 客户端          其他设备
        │                   │                   │
        └───── 只负责「显示」和「动效」 ─────────┘
```

### 强制规则

| 数据 | 唯一来源 | 本地禁止 |
|---|---|---|
| 播报币种 | 云端 `/queue` | ❌ 不得本地计算 |
| 播报时槽 | 云端 `endsAt` | ❌ 不得本地计时 |
| 播报历史 | 云端 `/history` | ❌ 不得本地积累 |
| 三类异动 | 云端 `/alerts` | ❌ 不得本地检测 |
| 涨跌榜 | 云端快照 | ✅ 本机渲染（数据同源） |

---

## 二、本地只做三件事

### 1. 渲染

```
从云端拿到数据 → 画到界面上
```

### 2. 动效

```
数据变化 → 流星飞入 → 播放提示音 → 高亮
```

### 3. 兜底

```
云端连续失败 3 次（约 90 秒）→ 临时启用本地调度
云端恢复 → 立刻交还给云端
```

---

## 三、禁止出现「双轨制」

### ❌ 错误做法

```javascript
// 云端说播 A，本地说播 B
// 两边都在调用 sigShow / focusShow
// → 两个流星、两次弹窗、数据最终停在 B

applyRight(cloudSym)   → focusShow(cloudRow)    // 云端
rotateFocusCard(rows)  → focusNext() → focusShow()  // 本地
```

### ✅ 正确做法

```javascript
// 云端接管时，本地调度函数全部直接返回

const rotateFocusCard = (rows, live) => {
  if (window.__MOSS_CLOUD_ACTIVE) return;   // ← 必须
  // ... 本地逻辑
};

const pushSignalSlot = (entry) => {
  if (window.__MOSS_CLOUD_ACTIVE) return;   // ← 必须
  // ... 本地逻辑
};

const maybeAlert = (r) => {
  if (window.__MOSS_CLOUD_ACTIVE) return;   // ← 必须
  // ... 本地逻辑
};
```

## 四、必须被拦截的本地函数清单

修改代码时，**逐项检查这些函数是否都有 `cloudActive` 守卫**：

| 函数 | 作用 | 必须拦截 |
|---|---|---|
| `pushSignalSlot` | 左侧入队 | ✅ |
| `sigNext` | 左侧切换 | ✅ 排定时器部分 |
| `sigRefill` | 左侧补充队列 | ✅ |
| `rotateFocusCard` | 右侧轮播 | ✅ |
| `focusNext` | 右侧切换 | ✅ 排定时器部分 |
| `focusEligible` | 右侧候选计算 | ✅ |
| `maybeAlert` | 异动检测（OI） | ✅ |
| 事件检测块 | 放量/大单检测 | ✅ |
| `showSignal` | 左侧弹窗 | ⚠️ 由 sigShow 调用 |
| `sigShow` | 左侧展示 | ⚠️ 只允许云端调用 |
| `focusShow` | 右侧展示 | ⚠️ 只允许云端调用 |

### 检查命令

```powershell
# 快速检查所有拦截是否存在
Select-String -Path desktop-webview\index.html -Pattern '__MOSS_CLOUD_ACTIVE' | Measure-Object
# 预期：至少 6 处
```

## 五、云端接口约定

### `/queue`

```json
{
  "ok": true,
  "left": {
    "symbol": "RAREUSDT",
    "startedAt": 1794816000000,
    "endsAt": 1794816300000,
    "remainingMs": 185000,
    "queue": ["AKEUSDT", "BARDUSDT"]
  },
  "right": { ... }
}
```

**客户端必须**：用 `endsAt` 设定时器，到点重新拉取。

### `/history`

```json
{
  "ok": true,
  "rows": [
    { "side": "left", "symbol": "AKEUSDT", "time": "16:06:10", "ts": 1794816370000, "meta": {...} }
  ]
}
```

### `/alerts`

```json
{
  "ok": true,
  "rows": [
    { "type": "large", "symbol": "RAREUSDT", "time": "16:15:23", "ts": 1794816923000, "usdt": 8500, "multiple": 45 }
  ]
}
```

## 六、动效触发规则

### 右上角（三类异动）

```
云端 /alerts 返回新异动（对比最新一条的 key）
  → 流星飞入
  → 播提示音
  → 新条目高亮 5 分钟（重绘后仍保留）
```

### 右下角（自选监控）

```
云端 /queue 的 symbol 变化
  → 流星飞入
  → 播提示音
  → 同币 3 秒内不重复
```

### 左侧（建仓信号）

```
云端 /queue 的 left.symbol 变化
  → 流星飞入
  → 播提示音
  → 弹警报窗口（90 秒自动关闭）
```

### ❌ 禁止

```
· 时间戳变化就飞流星（updatedAt 每分钟都变）
· 本地逻辑也飞流星（会和云端重复）
· 飞流星但数据没变
```

## 七、修改代码前的检查清单

每次改前端逻辑，必须确认：

```
□ 这个改动会不会让本地又「自己算」了？
□ 会不会和云端驱动冲突？
□ 会不会触发额外的流星/声音？
□ 新增的响应式逻辑有没有 cloudActive 守卫？
□ 重绘后状态会不会丢失？（高亮、选中）
```

---

## 八、出现问题的排查顺序

```
1. 看控制台有没有 [CLOUD] driver started
   → 没有：云端驱动没启动，检查 token

2. 看 [CLOUD-R] switch -> XXX 是否在打印
   → 没有：云端没在切换，检查 /queue

3. 如果同时看到两个流星
   → 抓调用栈：new Error().stack
   → 找出是哪个本地函数调用了 focusShow/sigShow
   → 给它加 cloudActive 守卫

4. 如果数据停在错误的币
   → 检查是否有本地逻辑在云端之后又覆盖了
```

## 九、架构图（正确状态）

```
云端 /queue (每 30 秒轮询 + endsAt 精确定时)
    │
    ├─→ applyLeft(sym)  → __MOSS_SIG_SHOW(entry)
    │       ↓
    │   流星 + 声音 + 弹窗 + 记录
    │
    └─→ applyRight(sym) → __MOSS_FOCUS_SHOW(row)
            ↓
        流星 + 声音 + 高亮 + 记录

云端 /alerts (同上轮询)
    │
    └─→ __MOSS_APPLY_CLOUD_ALERTS(rows, isNew)
            ↓
        重绘 3 条 + 流星 + 声音 + 5 分钟高亮

云端 /history (同上轮询)
    │
    └─→ window.__MOSS_CLOUD_HISTORY
            ↓
        弹窗里显示统一历史

本地兜底（仅云端连续失败 3 次时）
    └─→ sigNext / focusNext / maybeAlert
```
