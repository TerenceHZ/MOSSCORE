# MOSS CORE · 资金行为与多空信号逻辑 v1.0

> 状态：讨论稿，尚未实现  
> 记录日期：2026-11-09  
> 目标：先统一“资金行为、开多、开空”的判断逻辑，再进入代码实现  
> 原则：不把推测写成事实；所有信号必须经过价格结构确认

---

## 1. 核心原则

### 1.1 做“资金行为识别”，不做“庄家身份识别”

公开行情只能看到行为，不能确认：

- 下单的人是谁
- 是否同一账户
- 现货还是合约
- 是否对冲
- 是否挂单诱导
- 是否场外交易

因此界面统一使用：

```text
资金行为
疑似控盘
派发嫌疑
逼空风险
```

不使用：

```text
庄家已确认
庄家出货
```

### 1.2 概率，不是断言

任何行为状态都必须带：

```text
状态
置信度
证据
失效条件
```

### 1.3 价格确认优先

资金行为只能让信号进入“观察/武装”状态。

真正触发开多或开空，必须等：

```text
关键价位突破
或结构破坏
```

### 1.4 多空不对称

加密货币中：

- 上涨逼空速度快
- 下跌清算速度快
- 追空强势控盘币风险极高

所以空头信号应比多头更严格，并且必须过滤：

```text
BTC 强势上涨环境
OI 仍在增加
主动买入仍强
价格未破坏结构
```

## 2. 数据与指标定义

### 2.1 基础数据

| 指标 | 含义 |
|---|---|
| `change24h` | 24 小时涨跌幅 |
| `change5m` / `change15m` | 短周期涨跌幅 |
| `oiNotional` | 当前合约持仓名义价值 |
| `oi5m` / `oi15m` | 5 / 15 分钟 OI 变化率 |
| `oi24h` / `oi24hDelta` | 24 小时 OI 变化 |
| `quoteVolume24h` | 24 小时成交额 |
| `volRatio3m` | 3 分钟成交量 / 20 周期均量 |
| `change3m` | 3 分钟价格变化 |
| `largeUsdt` | 近期最大单笔成交名义价值 |
| `largeMultiple` | 最大单笔 / 平均单笔 |
| `largeSide` | 主动买入 / 主动卖出 |
| `change30s` | 30 秒价格变化 |
| `score` | 当前行情评分 |
| `stage` | 当前阶段：entry / watch / low |
| `fundingRate` | 资金费率（待接入） |
| `longShortRatio` | 全网/TOP5 多空比（已有） |
| `cvd` | 主动买卖累计差（待接入） |
| `atr` | 波动率尺度（待接入） |

### 2.2 价格 × OI 矩阵

| 价格 | OI | 含义 | 交易含义 |
|---|---|---|---|
| 上涨 | 增加 | 新多进场 | 趋势延续概率高 |
| 上涨 | 下降 | 空头回补 / 多头止盈 | 动能减弱，可能接近尾声 |
| 下跌 | 增加 | 新空进场 | 下跌延续概率高 |
| 下跌 | 下降 | 多头止损 / 清算 | 跌得快，但容易反抽 |

### 2.3 重要约束

OI 下降本身不等于派发。

高位 OI 下降可能是：

- 多头止盈
- 空头回补
- 杠杆资金降仓
- 换月 / 换所
- 短暂休息后继续拉升

所以：

```text
OI 下降只能进入“派发嫌疑”
不能单独触发空单
```

## 3. 资金行为阶段

### 3.1 吸筹

特征：

```text
价格横盘或缓慢抬升
OI 逐步增加
主动买入偏强
下跌有承接
成交量温和放大
```

含义：

```text
资金在低位收集筹码
```

交易含义：

```text
偏多观察，等待突破
```

### 3.2 拉升

特征：

```text
价格上涨
OI 增加
成交量放大
主动买入增加
资金费率转正
```

含义：

```text
新多进场，趋势延续
```

交易含义：

```text
顺势偏多
不逆势开空
```

### 3.3 控盘拉升

特征：

```text
短时间涨幅异常
OI 快速增加
成交额异常放大
大单主动买入
回撤很浅
连续创新高
```

含义：

```text
资金主导，存在逼空或控盘特征
```

交易含义：

```text
偏多，但追高风险高
禁止逆势开空
```

### 3.4 高位派发嫌疑

特征：

```text
前期涨幅很大
高位盘整时间较长
OI 从峰值回落
成交量衰减
主动买入转弱
CVD 转负
冲击前高失败
```

含义：

```text
多头可能在减仓，但不能确认派发完成
```

交易含义：

```text
进入观察，等待区间下沿破位
不直接开空
```

### 3.5 空头确认

特征：

```text
跌破盘整区下沿
跌破时放量
反抽区间下沿失败
形成更低高点
OI 增加或至少不再上升
```

含义：

```text
派发转为下跌趋势
```

交易含义：

```text
空单触发
```

### 3.6 逼空

特征：

```text
价格快速上涨
OI 下降
空头回补
资金费率偏高
```

含义：

```text
上涨由空头平仓推动，不一定是新多
```

交易含义：

```text
不追多
不逆势空
等待动能衰竭
```

### 3.7 不明

数据不足或信号冲突时：

```text
状态：不明
交易含义：不操作
```

## 4. 空头模型 A：高位派发 + 区间破位

### 4.1 前置条件：涨幅过大

建议初值：

```text
24H 涨幅 ≥ +15% ~ +20%
或 7D 涨幅 ≥ +30%
价格高于 1H VWAP 2 ATR
资金费率 ≥ +0.03% / 8H
全网多空比明显偏多
```

作用：

```text
确认多头拥挤，存在派发土壤
```

### 4.2 高位盘整

建议初值：

```text
盘整时间 ≥ 90 ~ 180 分钟
区间宽度 ≤ 1.5 ~ 2.5 ATR
至少 2 次冲击前高失败
成交量衰减至拉升段的 40% ~ 60%
```

### 4.3 OI 与筹码

```text
OI 从阶段高点回落 8% ~ 15%
价格没有同步创新高
CVD 转负或顶背离
大单主动买入减少
```

作用：

```text
进入“高位派发嫌疑”
只进入观察，不触发空单
```

### 4.4 触发条件

```text
15M 收盘跌破盘整区下沿
或跌破 15M EMA20 / VWAP
跌破幅度 ≥ 0.5 ATR
成交量 ≥ 20 周期均量的 2 倍
CVD 明显转负
```

### 4.5 确认条件

```text
反抽区间下沿失败
形成更低高点
没有重新站回区间
```

### 4.6 失效条件

```text
价格重新站回区间上沿
OI 重新增加且价格创新高
主动买入恢复
```

---

## 5. 空头模型 B：放量破位

### 5.1 触发条件

不使用固定百分比，使用 ATR：

```text
5M / 15M 跌幅 ≥ 1.5 ~ 2.5 ATR
成交量 ≥ 20 周期均量的 2.5 ~ 3 倍
CVD 快速转负
跌破前低或关键结构位
```

### 5.2 OI 分支

#### 分支 A：价格下跌 + OI 增加

```text
新空进场
下跌延续概率更高
可顺势空
```

#### 分支 B：价格下跌 + OI 下降

```text
多头清算
跌速快，但容易反抽
不追太低
等反抽失败再空
```

### 5.3 过滤条件

```text
BTC 4H 强势上涨 → 空头阈值提高
流动性差、盘口薄 → 降低仓位
资金费率极端负 → 防范空头拥挤反转
```

## 6. 多头模型

### 6.1 吸筹突破

```text
低位横盘
OI 增加
主动买入增强
成交量放大
突破区间上沿
回踩不破
```

### 6.2 回踩确认

```text
突破后回踩区间上沿
缩量
OI 不下降
重新转强
```

### 6.3 多头失效

```text
跌回区间
OI 快速下降
主动卖出增强
```

### 6.4 多头与空头的差异

```text
多头：吸筹 → 突破 → 回踩确认
空头：派发 → 破位 → 反抽失败
```

两者不能共用同一套方向性评分。

## 7. 信号状态机

### 7.1 状态

```text
IDLE        无信号
ARMED       条件具备，等待触发
TRIGGERED   关键位突破，信号触发
CONFIRMED   反抽/回踩确认
INVALIDATED 条件失效
EXPIRED     超时失效
```

### 7.2 冷却

```text
同币种同方向 4 小时内只触发一次
重新站回区间 → 立即失效
超过 60 分钟无延续 → 信号过期
```

### 7.3 展示

```text
ARMED      观察
TRIGGERED  弹窗/语音
CONFIRMED  加强提示
INVALIDATED 不弹窗或标记失效
```

## 8. 评分系统

### 8.1 资金行为置信度

用于弹窗“资金行为”模块：

```text
涨幅异常度           25
OI 扩张/收缩         20
成交量异常           20
主动大单/CVD         20
价格结构与回撤       15
```

输出：

```text
0–100 控盘/派发置信度
```

### 8.2 空头评分

```text
高位/涨幅过大        25
盘整与派发结构        25
OI 与 CVD 背离        20
破位触发              20
市场环境与流动性      10
```

建议：

```text
≥ 80：高置信空单
70–79：观察，等待确认
< 70：不弹窗
```

### 8.3 多头评分

```text
低位/跌幅过大        20
吸筹结构              25
OI 与主动买入         25
突破触发              20
市场环境与流动性      10
```

多头可以比空头略积极，但仍需结构确认。

## 9. 弹窗展示建议

在币种详情弹窗增加“资金行为”区块：

```text
CONTROL FLOW · 资金行为

状态：疑似控盘拉升
置信度：87 / 100

证据：
24H +227.3%
24H OI +264.4%
15M OI +3.29%
成交额 20.86 亿
主动大单 25K / 150 倍

阶段：主升 / 加速
风险：追高、逼空
空头：禁止逆势
失效条件：跌回区间 / OI 转负 / 主动买入消失
```

### 9.1 展示原则

- 不只显示一个“庄家”标签
- 必须显示证据
- 必须显示失效条件
- 必须区分“拉升”和“派发”
- 空头信号只能出现在派发确认之后

## 10. JCT 示例

以下是 2026-11-09 12:56 的行情快照，仅作为逻辑示例，不是永久结论。

```text
JCT / USDT

24H 涨幅：+227.3%
24H OI 增长：+264.4%
15M OI：+3.29%
24H 成交额：20.86 亿
单笔大单：25,070 USDT
大单倍数：150 倍
方向：主动买入
评分：100
```

### 当前判断

```text
价格↑ + OI↑ + 成交额放大 + 主动买入
→ 疑似控盘拉升
→ 偏多，但追高风险高
→ 禁止逆势开空
```

### 不能直接开空的原因

```text
OI 仍在增加
主动买入仍强
价格没有结构破坏
```

### 后续转空条件

```text
价格停止创新高
高位盘整 ≥ 90 分钟
OI 从峰值回落 8% ~ 15%
成交量衰减
主动买入转弱
CVD 转负
15M 跌破盘整区下沿
反抽失败
```

只有这些条件逐步满足，才从“控盘拉升”切换到“高位派发嫌疑”，再进入空头触发。

## 11. 风险控制

### 11.1 空单

```text
止损：区间上沿 + 0.5 ATR
第一目标：区间高度
第二目标：前低 / 1.5–2 ATR
最低盈亏比：1.5–2
```

### 11.2 多单

```text
止损：突破位下方 / 0.5 ATR
目标：前高 / 区间高度
```

### 11.3 仓位

```text
强控盘币：降低仓位
流动性差：降低仓位
BTC 强势逆势空：降低仓位或不做
```

## 14. 当前结论

1. “庄家识别”改称“资金行为识别”。
2. 高位 OI 下降只能进入派发嫌疑，不能直接开空。
3. 空头必须等价格结构破位。
4. 多头和空头使用不同的评分与触发条件。
5. JCT 这类价格与 OI 同涨的标的，应提示“疑似控盘拉升 / 禁止逆势空”，而不是直接给空单。
6. 先整理逻辑与阈值，再实现代码和回测。
